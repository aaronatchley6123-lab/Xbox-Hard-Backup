# XBXOwned — Xbox GDK & XDK Linux Studio

## Quick Start & Local Setup

When downloading this project zip archive, the `node_modules` folder (containing Vite and other packages) is excluded by default via `.gitignore`. 

To run the project locally on your machine (e.g. Linux/Kali/Windows), follow these steps:

1. Extract the downloaded project archive.
2. Open a terminal in the project root directory.
3. Install all dependencies (including Vite):
   ```bash
   npm install
   ```
4. Start the development server (runs Express + Vite middleware on port 3000):
   ```bash
   npm run dev
   ```
5. Open your browser at `http://localhost:3000`.
